# BURN-CALC v0.8

Додано журнал спостереження 0–48 годин із неперекривними часовими інтервалами, введеною інфузією, діурезом, САТ, ЧСС, лактатом, таблицею та графіком діурезу в мл/кг/год. Є експорт журналу в JSON та клінічного звіту HTML (відкрити у браузері та друкувати в PDF).

Поля за завершений інтервал, а не миттєва швидкість. Підсумки відображають лише введені записи, пропущені інтервали не інтерполюються. Записи не зберігаються після перезавантаження, якщо їх не експортувати.

Збережено блоки анатомічних сегментів, ступені I–IV, TBSA, ABSI, Revised Baux, інфузійні формули та клінічний скринінг.

**Увага:** прототип для дорослих, не валідований клінічно; коефіцієнти дрібних сегментів наближені. Не використовувати для автономного призначення інфузії або інших втручань.

Запуск: index.html; офлайн PWA через HTTPS/localhost.
